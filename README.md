# Playbox phone app

This folder turns the Playbox games into real iPhone and Android apps.

- `game/` the games themselves (same files as the web version, plus bundled fonts)
- `assets/` app icon and splash screen artwork
- `scripts/` small build helpers
- `codemagic.yaml` cloud build recipe (Codemagic builds the apps, no Mac needed)
- `docs/` privacy policy and support page (published with GitHub Pages)
- `store/` screenshots, icons and listing text for the App Store and Google Play

The step-by-step publishing guide explains everything else.
